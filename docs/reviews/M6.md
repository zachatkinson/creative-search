## The seven dimensions

**DRY and SOLID.** One `Block\SearchForm` renders the form for the block, the shortcode, the widget and the theme-form takeover; `Block\FormOptions` resolves the owner's settings and a block's overrides in one place; the script holds no string a translator needs (every word arrives translated in the context).

**Anti-patterns.** No framework, no jQuery; the Interactivity API is WordPress's own. No `!important`; CSS custom properties inherit the theme's presets; logical properties for right-to-left. The price HTML is set with `innerHTML` from the plugin's own same-origin route (WooCommerce's `wc_price()` output), the only place markup is inserted.

**Security.** The form submits `s` and `post_type=product` with GET; the block's attributes are escaped where they are printed (a script tag in the placeholder is tested); the click beacon sends only the query, the language, a type from an allow-list and an id.

**Accessibility.** The APG list-autocomplete combobox: a label (visible or visually hidden), `role="combobox"`, `aria-autocomplete="list"`, `aria-expanded`, `aria-controls`, `aria-activedescendant`; options named by their visible text (D-064); a polite live region with the count in words; Down and Up wrap, Enter opens or submits, Escape closes then clears, Tab closes, Alt+Down opens; focus stays in the field; 44 px rows (48 on a phone); reduced motion honoured; the form works with no script. The manual screen-reader pass is milestone 8's.

**Internationalisation.** Every word through the text domain in PHP, with `_n()` for counts; numbers formatted for the page's language in the script; the page's `lang` attribute selects the search language.

**Testing.** The state machine: typing below and above the minimum, the 150 ms debounce, stale answers dropped, the page cache, failures and 429s silent, "Searching…" after 400 ms, Down/Up wrapping with `aria-activedescendant`, Escape/Tab/Alt+Down, Enter on a row with the beacon's payload, Enter with no row, recent searches off by default and kept when on, an outside click. The browser runs above.

**Performance.** 2.6 kB of script, loaded as a module; one request in flight; answers cached for the page and by the server.
