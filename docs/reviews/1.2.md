## The seven dimensions

**DRY and SOLID.** The query is read once, by the same parser the search uses (`QueryParser`, with the same synonyms, now read once a request through `SearchService::synonymsFor()` and shared). The decisions are in the Domain (`FeatureFilters`, `CategoryMatcher`, pure and mutation-tested); `Search\QueryRoutes` reads WordPress for them; `Results\QueryRouter` decides the target and redirects; `ResultsView` prints the lines; `ResultsHooks` wires it. The filter is WooCommerce's own (`filter_*`, `query_type_*`), not a second filter of ours.

**Anti-patterns.** No new table: two autoloaded options, each deleted when what it reads changes and rebuilt by the next search (never on the request that saves a term). A routed request fetches nothing (`post__in` 0, no search clause). A shared word or a shared category name is never guessed at: the word stays a word, the categories are offered.

**Security.** Redirect targets come only from `get_term_link()`, `home_url()` and the shop permalink, through `wp_safe_redirect()`; filter slugs pass `sanitize_title()` and only existing `pa_` taxonomies survive the hook. `csearch_from` is honoured only with its signature (`wp_hash`), so a crafted link cannot put words on a category page; everything printed is escaped. Settings are sanitised (`pa_` names, at most 32 characters).

**Accessibility.** The lines are plain paragraphs with links whose text says where they go; two categories of one name carry their parents so no two links read the same (WCAG 2.4.4). The field on the page landed on keeps the query as typed. axe runs on the category line and the filtered results on a block theme and a classic one. The manual screen-reader pass is still **not run**.

**Internationalisation.** 12 new strings, all in Canadian French; the attribute-and-value pair and the category-and-parent pair carry context (`_x`); lists through `wp_sprintf( '%l' )`.

**Testing.** RoutingTest (16 tests): the golden routes, the page landed on, the log's counts, the settings and hooks, the phrase and minus cases, the maps forgotten on term and setting changes, no query once warm, the unsigned `csearch_from`. SkatehouseCopyTest round-trips WooCommerce's exporter and `export_wp()`. `tests/e2e/routing.spec.ts` on five browser projects: the category opened, the filter applied and removed, the two together. SkatehouseTest is written to the handoff's table and skips until the export exists.

**Performance.** A search page that is not routed adds no query once warm (tested): the attribute values and category names are autoloaded, the synonyms shared with the search. A routed request runs its count query and the redirect, nothing else. The 10,000-product CI job no longer slows as the catalogue grows.
