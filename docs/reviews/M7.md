# Milestone 7 review: Admin

Released in `v0.7.0` · 21 October 2026 · the seven-dimension review, the gate results and the independent spec review's findings with what was done about each.

## What the milestone was to build

From the spec: the four tabs, the product panel, importer and exporter columns, notices, `wp csearch synonyms`, `log`, `cache`, CSV import and export. Tests: nonces and capabilities refused; list tables paginate; synonyms apply at once; the Analytics numbers match the log; a CSV round trip. Done when axe is clean on every tab by keyboard alone.

All built and tested. Deviations, each with its decision: the product panel has no per-variation field (D-070), fallback products are chosen by SKU or ID rather than WooCommerce's picker (D-069), and three actions follow WordPress's link and self-post conventions instead of a form to `admin-post.php` (D-068).

## The seven dimensions

**DRY and SOLID.** One handler class for every admin action (`Admin\Actions`), each method returning where to go, so tests run without the redirect; tabs are classes with one `render()`; synonyms go through one `SynonymService` from the screen, the CSV import and WP-CLI; the index's health is one `Index\IndexHealth` read by the Tools tab, the notices and `/status`; explanations are one `Search\Explanation` for the CLI and the test search.

**Anti-patterns.** No chart library, no React screen, no new script dependency: WordPress's list table, form tables and notices, a server-drawn SVG chart (D-072) and a 40-line unbuilt progress script on `wp.apiFetch` (D-073).

**Security.** Capability then nonce before any input is read, for every action (tested for a customer, a forged nonce and another action's nonce); input sanitised by the settings sanitiser or the synonym validator; output escaped at the sink; CSV injection guarded both ways; the upload checked and read in memory; downloads `nosniff` and no-cache. docs/SECURITY.md has the v0.7.0 column.

**Accessibility.** Every control labelled (tested: each tab's visible inputs have ids, and ids are unique); the current tab marked `aria-current`; notices as `role="status"` (or `alert` for an error); the chart has a description and its numbers in a table; row actions named per row ("Delete “board”"); the rebuild's progress is a `<progress>` with a status line. Keyboard and axe as above. WooCommerce's selectWoo picker failed axe and was replaced (D-069). The manual screen-reader pass is milestone 8's.

**Internationalisation.** Every string through the text domain, `_n()` for counts, whole sentences (fixed after the review), numbers through `number_format_i18n()` and, in the script, the page's language.

**Testing.** The five tests the spec names, plus the Boosts and Tools saves, rebuild and cancel, the product panel's save and clamp, the product CSV columns and import normalisation, the warnings and their dismissal, the stale queue, and every new CLI command with its JSON and its failures.

**Performance.** Analytics reads aggregate in SQL over the indexed `created_at`; the log export streams 1,000 rows a read; the synonyms table pages 20 rows; users, products and terms on a screen are primed in one query each. The warnings cost five small queries on each admin screen for shop managers (D-075).
