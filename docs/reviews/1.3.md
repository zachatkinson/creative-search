## The seven dimensions

**DRY and SOLID.** The layers hold: the rules are pure in the Domain (`MatchExplainer`, `QueryRules`, `Scopes`, `Completions`, `MetaText`); WordPress is read in `Search\*`; the tables are the repositories'; cards are decorated by `Results\MatchDecorations`; `MatchHooks` only wires. `src/Domain` imports nothing from WordPress. Two duplicated bodies (minor 3, 4).

**Anti-patterns.** Direct SQL only in `src/Repository` and `src/Install`, through `prepare()`, id lists from integers; times through `Support\Clock`; no `date()`, no transients, no query on a save request. One N+1 on the search path (should-fix 4), rules re-tokenised on every first-page search (minor 7), an unbounded aggregate on the Tools tab (minor 8).

**Security.** `csearch_rules_save` goes through `Actions::handle()` (capability, then nonce), and `AdminTest`'s loop over `Actions::handlers()` refuses it. Redirect targets are checked by `wp_validate_redirect()` on save and after the filter, and sent with `wp_safe_redirect()`. `cat` is pattern-checked and resolved through `get_term_by()`. Output is escaped at the sink; suggested searches render through `data-wp-text`. Uninstall drops `facts` through `Tables::all()` and in the `uninstall.php` fallback. Gaps: the `dataLayer` push (blocker 1), CLI indexes (should-fix 3), SECURITY.md (should-fix 8).

**Accessibility.** The new rows follow the APG listbox rules: no focusable child in an option; "Add" is `aria-hidden` and pointer-only; Shift+Enter is announced through `aria-describedby` and its result through the live region. The scope control is a labelled native checkbox, 44 px. axe runs on the new panel states, the scoped form, the results page and the new tab. The manual script lacks the new controls (should-fix 9); the manual screen-reader pass is still not run.

**Internationalisation.** Every new string through the text domain, with context where a word is ambiguous; plurals through `_n()`; the scoped count names the category; `fr_CA` complete. Variation facts are in the base language on every language's document, unrecorded (minor 5).

**Testing.** Every feature has unit, integration and browser tests, including schema 2 → 3 and the CLI writes. Untested: D-105's one extra query on a warm results page with cards (should-fix 5), D-107's "no reason until the rebuild" (should-fix 1), a scoped ranking in `QueriesExplainTest` (should-fix 6).

**Performance.** Details only for the shown products, then cached; the scope runs inside the one ranking statement through `term_relationships`' primary key; cache keys include `scope`, `strong`, the pins and the panel flags. A cold `/suggest` adds the log prefix, a dictionary lookup, the first ten products' categories and `get_terms`, the facts and the per-field terms; the benchmark seeds the log. QUERIES.md is not refreshed (should-fix 6).
