# Accessibility

Two layers: axe-core runs in CI on every screen and state (Playwright), and once per release a person who did not write the code runs the 15-minute script below with VoiceOver on Safari and NVDA on Firefox, and records the result here.

## Rules (spec: Quality bar → Accessibility)

The search bar is an APG list-autocomplete combobox: a label, `aria-expanded`, `aria-controls`, `aria-activedescendant`, options with accessible names ("KAZUMI Skate Deck, Dealer, $84.99, in stock"); keyboard parity (Down, Up, Enter, Escape, Home, End, Tab, Alt+Down); a polite live region that says how many suggestions; focus never trapped; 24 px targets (44 px rows on desktop, 48 px on a phone); visible focus; `prefers-reduced-motion` honoured; every admin screen keyboard-complete; colour never the only signal.

## The manual script (15 minutes)

Run on the shop with the block in the header and a catalogue of at least 300 products. Record pass/fail per step, the screen reader's words where they matter, and the date and tester.

### Shop

1. Load the shop's front page. Tab to the search field. Hear: the label, "combobox", "collapsed" (or equivalent).
2. Type `kaz`. Hear the live region: "6 suggestions" (or the count). The panel is visible under the field.
3. Press Down. Hear the first row: product name, price, stock. The row is visually highlighted. Focus stays in the field (the caret is still there).
4. Press Down five more times, then once more: the highlight wraps to the first row.
5. Press Up: the highlight wraps to the last row ("See all results for kaz").
6. Press Escape: the panel closes, the text stays. Press Escape again: the text clears.
7. Type `kazumi deck`, press Down twice, press Enter: the product page opens.
8. Go back. The field has the last query; press Alt+Down: the panel reopens with the last answer.
9. Type `snowboard`. Hear "No suggestions". The panel shows a no-results row.
10. Clear the field with the clear button (Tab to it, Enter). Hear the field is empty.
11. Type `deck` and press Enter without opening a row: the results page loads. Hear the result count ("23 results for deck") as the page's heading or first announcement.
12. On the results page, Tab to the sort menu: "Relevance" is the selected option; change it to "Price: low to high" with the keyboard; the list reorders.
13. Zoom to 200 %: the panel and the results stay usable, nothing overlaps.
14. Turn on reduced motion in the OS: the panel appears without a fade.
15. On a phone (or a 375 px viewport with touch): tap the field, type, tap a row. Rows are at least 48 px tall.

### Admin (keyboard only)

16. WooCommerce → Search → Analytics: Tab through the period selector, the chart (it has a text alternative), the tables (sortable headers announce their state), the Explain and Export buttons.
17. Synonyms: add a synonym with the keyboard alone; hear the notice; delete it; hear the notice.
18. Boosts and exclusions: add a rule; hear the notice.
19. Tools: start a rebuild; the progress is announced (live region); Cancel is reachable.
20. Product edit screen: the Search panel's boost and exclude fields are labelled and in the tab order.
